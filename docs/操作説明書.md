# ashiato 操作説明書

## 1. アプリでできること

- GPSで移動した場所を記録し、地図上に経路として表示する
- 記録した地点に名前とメモを付け、お気に入りスポットとして保存する
- お気に入りスポットに写真・動画を添付する
- ログインアカウント単位で足跡・スポットをスプレッドシートと同期する

この説明書は公開Web版を対象としています。GPSの利用にはHTTPS接続と端末の位置情報許可が必要です。

## 2. 登録・ログイン

1. 公開URLを開きます。
2. 初めて使う場合は「初めて利用する方はこちら（新規登録）」を選びます。
3. 表示名、メールアドレス、12〜128文字のパスワードを入力します。
4. パスワードをもう一度入力し、足跡・スポット情報の保存について確認するチェックを入れます。
5. 「登録して開始」を押します。登録済みの場合はメールアドレスとパスワードを入力し、「ログイン」を押します。

ログイン状態は7日間のHttpOnly Cookieで維持されます。ログインできない場合は入力内容を確認してください。5回続けて認証に失敗すると、そのアカウントは15分間ログインできません。

> パスワードの再設定、メールアドレス確認、アカウント削除機能は現在ありません。忘れたパスワードをアプリから再発行することはできません。

## 3. 足跡マップ

- **足跡の記録を開始**: 端末が位置情報の許可を求めたら許可します。地図上に記録地点と経路が表示されます。
- **記録を一時停止**: GPS記録を停止します。すでに保存された地点は削除されません。
- **現在地を表示**: 最後に記録した地点へ地図を移動します。まだ地点がない場合は、先に記録を開始してください。
- 左側の「最近の記録」または地図上の地点を選ぶと、その地点をスポットに保存できます。
- 地図はOpenStreetMapの地図タイルを利用します。地図の利用時には地図配信元へ表示範囲が伝わります。

### GPS利用時の注意

- 初回の位置情報許可を拒否した場合は、ブラウザー／端末の設定からashiatoの位置情報を許可してください。
- Web版はページを開いている間にGPSを記録します。画面ロック中、別アプリへの切替中、ブラウザーを閉じた後の継続は保証されません。
- GPS精度、取得間隔、電池消費は端末・OS・電波環境で変わります。
- 記録間隔は「記録の設定」から10秒、30秒、1分を選べます。短い間隔は経路を細かく記録しますが、電池消費が増える場合があります。

## 4. お気に入りスポット

1. 地図上の記録地点、または最近の記録一覧から地点を選びます。
2. 「お気に入りの場所にする」でスポット名を入力します。メモは任意です。
3. 「スポットに保存」を押します。
4. 「お気に入りスポット」メニューからスポットを選ぶと、地図上の場所・メモ・添付ファイルを確認できます。

スポットの編集・削除機能は現在ありません。保存先はログインアカウントにひもづきます。

## 5. 写真・動画

1. お気に入りスポットを開き、「写真・動画を追加」を押します。
2. 端末から画像または動画ファイルを1つ選択します。
3. 初回はGoogle Driveへのアクセス許可を求められるので、許可します。
4. 完了メッセージが表示されたら、添付ファイル名からDrive上のファイルを開けます。

ファイル本体はGoogle Driveに保存されます。アプリとスプレッドシートにはファイル名、種類、DriveのURLなどの参照情報を保存します。Drive連携のGoogleアカウントは、足跡アルバムのメールアドレス・パスワードとは別です。アップロード後も同じGoogleアカウントでDriveにアクセスしてください。

## 6. 同期とログアウト

- GPS地点やスポットはまずこのブラウザーの端末内に保存されます。
- ログイン後はログイン時に一度同期します。新しく記録・作成したデータを別端末にも反映するには、サイドバーの「思い出を同期」または設定画面の「アカウントに同期」を押します。
- 設定画面にはログイン中の表示名とメールアドレスが表示されます。
- ログアウトは「記録の設定」画面下部の「ログアウト」から行います。ログアウトしても、スプレッドシートや端末内のデータは削除されません。
- 同期エラーが出た場合は、ネットワーク接続とログイン状態を確認し、再度同期してください。ログイン期限切れの場合は再ログインしてください。

## 7. ホーム画面への追加

スマートフォンのブラウザーの共有／メニューから「ホーム画面に追加」を選ぶと、ashiatoをアプリのように起動できます。これはWeb版のショートカットであり、Web版のGPSバックグラウンド制約は変わりません。

## 8. データとプライバシー

- アカウント情報と同期データは、アプリ運営者が管理するGoogleスプレッドシートに保存されます。
- パスワードそのものは保存せず、ソルト付きPBKDF2-HMAC-SHA256ハッシュを保存します。
- GPS座標は個人情報になり得ます。利用目的を理解したうえで記録・同期してください。
- 端末内データはブラウザーのIndexedDBに保存されます。ブラウザーのサイトデータを消去すると、まだ同期していないデータは失われる可能性があります。
- 写真・動画は、選択したGoogle Driveアカウントの保存領域・共有設定に従います。
