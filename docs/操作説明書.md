# ashiato 操作説明書

## 1. アプリでできること

- GPSで移動した場所を記録し、地図上に経路として表示する
- 記録した地点に名前・住所・説明を付け、お気に入りスポットとして保存する
- 公開を選んだお気に入りを、他のユーザーの地図におすすめスポットとして表示する
- お気に入りスポットに写真・動画を添付する
- ログインアカウント単位で足跡・スポットをスプレッドシートと同期する

この説明書は公開Web版を対象としています。GPSの利用にはHTTPS接続と端末の位置情報許可が必要です。

## 2. 登録・ログイン

1. 公開URLを開きます。
2. 初めて使う場合は「初めて利用する方はこちら（新規登録）」を選びます。
3. 表示名、メールアドレス、12〜128文字のパスワードを入力します。
4. パスワードをもう一度入力し、足跡・スポット情報の保存について確認するチェックを入れます。
5. 「登録して開始」を押します。登録済みの場合はメールアドレスとパスワードを入力し、「ログイン」を押します。

ログイン状態は7日間のHttpOnly Cookieで維持されます。ログインできない場合は入力内容を確認してください。5回続けて認証に失敗すると、そのアカウントは15分間ログインできません。

### パスワードを忘れた場合

1. ログイン画面の「パスワードを忘れた方はこちら」を押します。
2. 登録したメールアドレスを入力し、「ワンタイムパスワードを送信」を押します。
3. 届いたメール（件名「【ashiato】パスワード再設定の確認コード」）に記載された6桁のワンタイムパスワードを入力します。
4. 新しいパスワード（12〜128文字）を2回入力し、「パスワードを変更してログイン」を押します。

ワンタイムパスワードの有効期限は15分で、使えるのは1回だけです。5回続けて間違えると無効になるため、再送信してください。再送信は60秒に1回までです。メールが届かない場合は、迷惑メールフォルダーも確認してください。1日に送れるメールの数には上限があります。上限に近づくと「本日のメール送信数が無料枠の上限に近づいた」と表示されるため、翌日以降にもう一度お試しください。パスワードを変更すると、ログイン失敗によるロックも解除されます。

> メールアドレス確認、アカウント削除機能は現在ありません。

## 3. 足跡マップ

- **足跡の記録を開始**: 端末が位置情報の許可を求めたら許可します。地図上に記録地点と経路が表示されます。
- **記録を一時停止**: GPS記録を停止します。すでに保存された地点は削除されません。
- **現在地を表示**: 最後に記録した地点へ地図を移動します。まだ地点がない場合は、先に記録を開始してください。
- 地図左上の検索欄に施設名や住所を入力して「検索」を押すと、候補が地図上にピン表示されます。候補を選ぶと地図が拡大し、場所の名前・住所・種類・座標を確認できます。
- 地図右上の切替ボタンで「標準」「地形」「航空写真」を選べます。選択した表示方法は端末に保存され、次回も引き継がれます。
- 地図右上の「◯件の記録地点」ボタンを押すと、記録地点ごとの〇（マーカー）の表示と非表示を切り替えられます。最初は非表示で、経路の線だけを表示します。
  - 〇を表示すると、地図に見えている範囲の地点だけを描きます。表示範囲に1,500件を超える地点がある場合は、間引いて表示します。
  - 〇にカーソルを合わせると記録日時を確認できます。地点が多い場合は、非表示のままのほうが地図の動作が軽くなります。
- 足跡の記録中は、記録地点の周囲約20mをマーキングします。
  - 標準・地形：〇を表示しているときに、拡大すると経路と同じ色の円で表示します。
  - 航空写真：〇の表示とは関係なく、マーキング内をカラー、外側を薄い白黒で表示します。
  - 通常モードや場所の検索中は、マーキングを使わない通常の地図表示になります。
- 左側の「最近の記録」または地図上の地点を選ぶと、その地点をスポットに保存できます。
- 標準はOpenStreetMap、地形はOpenTopoMap、航空写真はEsri World Imageryの地図タイルを利用します。地図の利用時には選択した地図配信元へ表示範囲が伝わります。

### GPS利用時の注意

- 初回の位置情報許可を拒否した場合は、ブラウザー／端末の設定からashiatoの位置情報を許可してください。
- Web版はページを開いている間にGPSを記録します。画面ロック中、別アプリへの切替中、ブラウザーを閉じた後の継続は保証されません。
- GPS精度、取得間隔、電池消費は端末・OS・電波環境で変わります。
- 記録間隔は「記録の設定」から10秒、30秒、1分を選べます。短い間隔は経路を細かく記録しますが、電池消費が増える場合があります。
- 「記録の設定」→「位置情報ファイルをインポート」→「ファイルを選択」で位置情報ファイルを選ぶと、GPS地点を足跡マップに追加できます。取り込んだ地点は端末に保存され、続けてアカウント（スプレッドシート）へ自動で同期されます。重複する地点は追加されません。同期に失敗した場合は、通信状態を確認して「アカウントに同期」を押してください。
  - 対応形式（100MBまで）
    - GoogleマップのタイムラインJSON（Googleデータエクスポートの旧形式、Android・iPhoneの端末からエクスポートした形式）
    - GPX（登山・ランニング・サイクリングアプリなど）
    - KML（Google Earthなど）
    - GeoJSON
    - CSV：1行目に、緯度・経度・日時の列名が必要です。例：`緯度,経度,日時` または `latitude,longitude,time`。精度の列（`accuracy` / `精度`）は省略できます。
  - 日時が記録されていない地点は取り込めません。
  - スマートフォンのタイムラインの書き出し方法は、インポート欄の「スマートフォンからタイムラインを書き出すには」を開くと表示されます。
  - 取り込みが終わると、結果の画面が表示されます。
    - **インポートに成功しました**：追加件数、登録済みでスキップした件数、日時がなく除外した件数、記録の期間、同期の結果を表示します。
    - **端末には追加しましたが、同期に失敗しました**：同期できなかった原因を表示します。「もう一度同期」で再試行できます。
    - **追加する新しい地点はありませんでした**：ファイル内の地点がすべて登録済みの場合です。
    - **インポートに失敗しました**：失敗の「原因」と「対処方法」を表示します（例：形式が違う、ファイルが途中で切れている、CSVに必要な列がない、100MBを超えている）。

## 4. お気に入りスポット

1. 地図上の記録地点、または最近の記録一覧から地点を選びます。
2. 「お気に入りの場所にする」でスポット名を入力します。住所と説明は任意です。公開範囲（非公開／フォロワー限定／全体公開）を選べます。初期設定は非公開です。
3. 「スポットに保存」を押します。
4. 「お気に入りスポット」メニューからスポットを選ぶと、名前・住所・説明・公開範囲・リスト・マークを編集できます。保存内容はアカウントのスプレッドシートに同期されます。
5. 全体公開のスポット（フォローしている人のフォロワー限定のスポットを含む）は、アカウントの同期後、ほかのユーザーの地図におすすめマーカーとして表示されます。マーカーを選ぶと、スポット情報と公開した人（ニックネーム）を確認できます。

### リストとマーク

- 「お気に入りスポット」メニューの上部で、表示するリスト（すべて／各リスト／未分類）を切り替えられます。リストを選ぶと、地図にもそのリストのお気に入りだけが表示されます。
- 「＋リスト」で新しいリストを作れます。リスト名と、地図に表示するマーク（記号と色）を設定します。リストを選んでから「編集」を押すと、名前・マークの変更や、リストの削除ができます。
- リストを削除しても、お気に入り自体は削除されません。そのリストに入っていたお気に入りは「未分類」に移ります。
- お気に入りの保存画面と詳細画面で、入れるリストとマークを選べます。
  - マークは「リストのマークを使う」が初期設定です。チェックを外すと、そのお気に入りだけ別の記号・色にできます。
  - リストにもマークにも指定がない場合は、♥ で表示します。
- リストを選んだ状態で地点からお気に入りを保存すると、そのリストに入ります。
- リストとマークもアカウントのスプレッドシートに同期され、別の端末でも同じように表示されます。

公開中のスポット情報（名前・住所・説明・位置・表示名）は他のログインユーザーに共有されます。写真・動画は共有されません。公開を解除すると、次回の同期以降、他のユーザーの地図から非表示になります。スポットの削除機能は現在ありません。

## 4-2. みんな（SNS）

メニューの「みんな」から、ほかの利用者とお気に入りを共有できます。

### ニックネーム
- フォローしたり、フォローされたりするには、ニックネームの設定が必要です（する側・される側の両方）。
- 「みんな」を開き、「ニックネームを設定しましょう」に入力して保存します。2〜20文字で、文字・数字・アンダースコア（_）が使えます。ほかの人と同じものは使えません（大文字・小文字、全角・半角の違いは同じとみなします）。
- ほかの人に表示されるのはニックネームだけです。メールアドレスや登録時の表示名は表示されません。
- ニックネームは変更できますが、消すことはできません。

### フォロー
- 検索欄にニックネームの一部を入れて検索し、「フォロー」を押します。承認は不要で、すぐにフォローできます。
- 「フォロー中」「フォロワー」から、一覧の確認、フォロー解除、フォロワーから外す（相手には通知されません）ができます。

### 公開範囲
お気に入りとリストごとに、公開範囲を3段階から選べます（初期設定は非公開）。

| 公開範囲 | 見られる人 |
|---|---|
| 非公開 | 自分だけ |
| フォロワー限定 | 自分をフォローしている人 |
| 全体公開 | ログインしている全員。地図のおすすめにも表示されます |

- リストを公開すると、中のお気に入りも同じ範囲に公開されます。お気に入りの公開範囲は、自分の設定とリストの設定のうち、広い方になります。
- 公開範囲の変更は、同期した時点で反映されます。
- 写真・動画は共有されません。

### タイムラインとプロフィール
- 「みんな」の「TIMELINE」に、フォローしている人の新着お気に入りが表示されます。地図にも表示され、選ぶと詳細を確認できます。
- ユーザーを選ぶと、その人が公開しているリストとお気に入りが表示されます。リストで絞り込むと、地図の表示も切り替わります。
- 地図のおすすめスポットの詳細から「プロフィールを見る」で、その人のプロフィールを開けます。
- 自分のプロフィール（「公開中の内容」）では、ほかの人に公開している内容を確認できます。

## 5. 写真・動画

1. お気に入りスポットを開き、「写真・動画を追加」を押します。
2. 端末から画像または動画ファイルを1つ選択します。
3. 初回はGoogle Driveへのアクセス許可を求められるので、許可します。
4. 完了メッセージが表示されたら、添付ファイル名からDrive上のファイルを開けます。

ファイル本体はGoogle Driveに保存されます。アプリとスプレッドシートにはファイル名、種類、DriveのURLなどの参照情報を保存します。Drive連携のGoogleアカウントは、足跡アルバムのメールアドレス・パスワードとは別です。アップロード後も同じGoogleアカウントでDriveにアクセスしてください。

## 6. 同期とログアウト

- GPS地点やスポットはまずこのブラウザーの端末内に保存されます。お気に入りスポットを新規登録・編集すると、スプレッドシートへ自動で同期します。
- ログイン後はログイン時に一度同期します。GPS記録などを別端末にも反映するには、サイドバーの「思い出を同期」または設定画面の「アカウントに同期」を押します。
- 設定画面にはログイン中の表示名とメールアドレスが表示されます。
- ログアウトは「記録の設定」画面下部の「ログアウト」から行います。ログアウトしても、スプレッドシートや端末内のデータは削除されません。
- 同期エラーが出た場合は、ネットワーク接続とログイン状態を確認し、再度同期してください。ログイン期限切れの場合は再ログインしてください。

## 7. ホーム画面への追加

スマートフォンのブラウザーの共有／メニューから「ホーム画面に追加」を選ぶと、ashiatoをアプリのように起動できます。これはWeb版のショートカットであり、Web版のGPSバックグラウンド制約は変わりません。

## 8. データとプライバシー

- アカウント情報と同期データは、アプリ運営者が管理するGoogleスプレッドシートに保存されます。
- パスワードそのものは保存せず、ソルト付きPBKDF2-HMAC-SHA256ハッシュを保存します。
- GPS座標は個人情報になり得ます。利用目的を理解したうえで記録・同期してください。
- 名前・住所検索では、入力した検索語がOpenStreetMapの検索サービス（Nominatim）に送信されます。検索結果はOpenStreetMap contributorsが提供します。
- 端末内データはブラウザーのIndexedDBに保存されます。ブラウザーのサイトデータを消去すると、まだ同期していないデータは失われる可能性があります。
- 写真・動画は、選択したGoogle Driveアカウントの保存領域・共有設定に従います。
